## О проекте

Учебный интернет-магазин электроники **TechStore**: смартфоны, ноутбуки и наушники.
Предметная область та же, что в КР №1 ([kr1-html-css-shop](https://github.com/yeayaeyae/kr1-html-css-shop)),
но интерфейс заново свёрстан на компонентах и сетке Bootstrap.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения

Bootstrap подключён **локально**, без CDN. Файлы фреймворка (compiled-версия) размещены в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css` — подключается в `head`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — подключается перед `</body>`, нужен для мобильного меню, модального окна, accordion, carousel, tabs и toast.

Собственный файл `css/custom.css` подключается **после** Bootstrap, чтобы переопределять его стили:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
```

## Bootstrap-сетка

`container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `col-xl-*`, отступы `g-3`/`g-4`.
Карточки товаров: 1 колонка на телефоне → 2 на планшете → 3 на десктопе.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** из `vendor/bootstrap/` вместо CDN.
2. **Дополнительные страницы:** `contacts.html` с формой обратной связи и `faq.html` с accordion.
3. **Дополнительные компоненты:** carousel, tabs, toast, pagination, breadcrumb, form-switch.
4. **Рабочий каталог:** фильтр по категории и цене, сортировка по цене, пагинация (4 товара на странице), сообщение `alert`, если ничего не найдено, счётчик найденных товаров.
5. **Единая страница товара:** `product.html?product=<id>` подставляет название, цену, badge и таблицу характеристик для любого из 6 товаров.
6. **Сценарий заявки:** кнопка «Заказать» в каталоге и на товаре сразу выбирает товар в форме; быстрая заявка в модальном окне; Bootstrap-валидация с подсказками и уведомление toast после отправки.
7. **Визуальная целостность:** фирменные цвета через CSS-переменные в `custom.css`, переопределение `btn-primary`, hover-эффект карточек, видимый фокус.
8. **Адаптивность:** sticky-фильтр на десктопе, перестройка сетки, кнопки во всю ширину на телефоне, кнопка «Наверх».

## Как проверить

1. Открыть `index.html` в браузере (или ссылку GitHub Pages).
2. Сузить окно до ширины телефона — меню сворачивается в кнопку, карточки встают в одну колонку.
3. В каталоге отметить «Наушники» и цену «До 20 000 ₽» — останутся 2 товара; выбрать «Сначала дороже».
4. Нажать «Подробнее» у любого товара — откроется его страница; переключить вкладки.
5. Нажать «Быстрая заявка» — откроется модальное окно; отправить пустую форму — появятся подсказки.
6. Заполнить форму на `order.html` и отправить — появится уведомление toast.

## Локальный запуск

Сборка не нужна: Bootstrap лежит в `vendor/`, интернет не требуется.

1. Скачать репозиторий: `git clone https://github.com/yeayaeyae/kr2-bootstrap-shop.git`.
2. Открыть `index.html` двойным кликом или через Live Server в VS Code.
